**场景 1（类型 2）：** *能力名称：“批判性思维” / 能力定义：“分析信息、评估证据并构建有理有据论证的能力” / 阶段范围：“A–D 阶段（5–14岁）” / 项目宗旨：“我们的使命要求学生能够为需要他们的世界做出贡献。为复杂的真实世界问题做出贡献需要批判性思考的能力——区分强证据与弱证据、识别假设，并构建能经受挑战的论证。没有批判性思维，学生就会沦为他人结论的消费者，而非自己结论的生产者”*

## 学习目标集：批判性思维

**能力：** 批判性思维
**定义：** 分析信息、评估证据并构建有理有据论证的能力
**项目宗旨：** 为需要批判性思考者的世界做出贡献——培养自己产出结论的人，而非消费他人结论的人
**学习目标数量：** 2——分析与论证是真正不同的能力（你可以只分析不论证，也可以论证得很有说服力却缺乏良好分析）

### 能力审视

该能力界定清晰。它描述了一项真正的能力（而非主题），直接服务于使命（批判性贡献需要批判性思维），且足够宽泛以适用于所有学科与项目。定义包含三个要素：分析、评估、构建论证。分析与评估联系紧密（评估本身就是一种分析），因此合并为一个 LT。论证构建则截然不同——它是一种生产性能力（建构某物），而非分析性能力（拆解某物）。共2个 LT。

### 第0步：知识类型分类

| LT 分支 | 知识类型 | 评估路径 | 推理依据 |
|---|---|---|---|
| 证据分析 | 类型 2 | 推理质量量规 | 存在多种有效的分析框架；推理质量决定结果；没有单一正确答案；分析深度随经验增长。向新情境的迁移是检验标准。 |
| 有理有据的论证 | 类型 2 | 推理质量量规 | 论证质量通过推理老练度而非正误来评估；存在多种合理立场；发展的是构建与捍卫立场的能力，而非背诵正确答案。 |

未检测到类型 3 要素。作为**倾向**的批判性思维（自发质疑的习惯，而不仅仅是被要求时才质疑）是一种真实且重要的能力——但它不是本项能力所测量的内容。如果项目希望捕捉批判性思考的倾向，那需要一个拥有自身观察路径的独立类型 3 学习目标。

### 学习目标拆解

**LT1：证据分析**
- **定义：** “我能够审视信息与证据，识别出什么是相关、可靠且重要的”
- **知识类型：** 类型 2
- **评估路径：** 推理质量量规
- **前置条件：** 不适用（N/A）
- **学理依据：** 本 LT 涵盖批判性思维的**分析**维度——拆解信息、评估其质量并判断什么重要的能力。它是批判性思维的输入端：加工所给定的材料。

**LT2：有理有据的论证**
- **定义：** “我能够构建一个由证据和推理支持的清晰论证”
- **知识类型：** 类型 2
- **评估路径：** 推理质量量规
- **前置条件：** 不适用（N/A）
- **学理依据：** 本 LT 涵盖批判性思维的**生产**维度——立论、用证据支撑并以可接受审视和挑战的方式呈现的能力。它是批判性思维的输出端：产出一个立场。

**拆解检验：**
- **覆盖度：** LT1（分析）与 LT2（论证）共同覆盖了“批判性思维”的完整含义。既能分析证据又能构建有理有据论证的学生就是批判性思考者。
- **区分度：** 学生可能擅长分析但论证薄弱（看得见漏洞但无法清晰阐述自己的立场），也可能擅长论证但分析薄弱（说理极具说服力但依据的是糟糕的证据）。这两者确实是不同的能力。
- **可评估性：** 两个 LT 都能在学生作品中产生可观察证据——分析可见于学生如何评估来源、识别偏见与筛选证据；论证可见于学生如何组织主张、提供支持与回应反方立场。
- **知识类型检验：** 两个 LT 均为类型 2。无复合知识类型问题。

### 阶段陈述

**LT1：证据分析**
知识类型：类型 2
评估路径：推理质量量规
撰写模式：模式 2

| 阶段 | 陈述 | 进阶杠杆 |
|---|---|---|
| A | 我能够从给定来源中识别相关信息 | 范围：单一来源；独立性：给定来源 |
| B | 我能够比较来自多个来源的信息并识别差异 | 复杂度：多个来源；推理：比较 |
| C | 我能够评估来源的可靠性并解释为什么某些证据比其他证据更有力 | 推理：评价性判断；精确度：解释原因 |
| D | 我能够分析相互竞争的证据、识别假设与偏见，并论证哪项证据对给定目的最可信 | 迁移：将分析应用于新情境；复杂度：竞争性证据、多重标准 |
| E | 我能够评估一组证据、识别可用材料中的系统性缺口或偏见，并论证哪种解释框架最契合该目的 | 推理：将证据基础作为整体进行评估，而非仅比较单个来源；范围：跨一组材料的系统模式，而非单一对比 |
| F | 我能够针对一组证据构建批判性说明，解释其产出条件、所服务的利益以及其所能证明的限度 | 独立性：自主定向的批判性建构；推理：对证据基础本身的二阶分析 |

**LT2：有理有据的论证**
知识类型：类型 2
评估路径：推理质量量规
撰写模式：模式 2

| 阶段 | 陈述 | 进阶杠杆 |
|---|---|---|
| A | 我能够陈述我的观点并给出一个理由 | 独立性：单一主张、单一理由 |
| B | 我能够提出一个由不止一条证据支持的主张 | 复杂度：多重证据点 |
| C | 我能够构建一个包含清晰主张、支持证据以及对不同观点回应的论证 | 范围：包含反方立场；推理：结构意识 |
| D | 我能够建立一个整合证据、回应反方论证并评估自身立场强度的持续论证 | 迁移：对论证的自我评估；精确度：持续且整合 |
| E | 我能够构建一个整合竞争性视角、预判可能异议并回应反方立场最强版本的持续论证 | 复杂度：整合竞争性视角；推理：钢人化（steelmanning）反方立场 |
| F | 我能够评估自身论证的局限——识别证据在何处不足、哪些假设起承重作用，以及需要什么才能改变我的立场 | 独立性：对自身论证的自我批判性评估；推理：识别认知限度 |

### 质量检查

- [x] **单一构念规则：** 每条陈述评估一个连贯的能力。LT1 始终关乎审视证据；LT2 始终关乎构建论证。没有陈述将两者混为一谈。
- [x] **复合知识类型检查：** 两个 LT 均为类型 2。无混合类型要素。
- [x] **无括号或行内示例：** 全篇未见。无“例如”或“诸如”。
- [x] **仅使用可观察动词：** 识别、比较、评估、解释、分析、论证、陈述、提出、构建、建立、整合、回应。无“理解”、“知道”或“欣赏”。
- [x] **纵向连贯性：** 在每个 LT 内部，D阶段真正比 A阶段更进阶——通过杠杆实现的进阶清晰且连续。
- [x] **横向连贯性：** 两个 LT 的 B阶段描述了相似的发展要求——比较来源与提出多证据主张均处于 B阶段水平。
- [x] **LT 定义描述所有阶段：** “我能够审视信息与证据，识别出什么是相关、可靠且重要的”适用于所有阶段——A阶段以简单方式做到（单一来源），D阶段以老练方式做到（带偏见分析的竞争性证据）。
- [x] **知识类型字段：** 两个 LT 均明确标注了类型 2 与推理质量量规。
- [x] **评估路径核验：** 推理质量量规适用于类型 2 水平性知识。向新情境的迁移是检验标准。
- [x] **2个 LT：** 合理——分析与论证确实相互独立。

### 已知局限

1. **批判性思维既具有领域一般性，也具有领域依赖性。** 在科学上能批判性思考的学生未必能将该技能迁移到历史中。这些 LT 写成领域一般性能力，但教师应预料批判性思维在不同学科中呈现不同面貌，且跨学科迁移需要明确教学。

2. **A阶段刻意保持朴素。** “我能够陈述我的观点并给出一个理由”对于批判性思维而言看似过于简单，但它准确代表了 5–7 岁儿童的发展起点。强行把 A阶段推向“分析多元视角”只会设定一个不可能达到的期望，进而产出虚假合规或教师挫败。

3. **这些 LT 未捕捉批判性思考的“倾向”。** 学生可能拥有分析证据的**能力**（被要求时能做到），却没有**倾向**（不会自发去做）。如果项目需要该倾向，请撰写一个独立的类型 3 LT——“作为实践的批判性思维”——通过多信息源观察而非量规进行评估。

## 学习目标集：自我调节

**能力：** 自我调节
**定义：** 跨不同情境监控并调整自身情绪与行为反应的能力
**项目宗旨：** 自我调节是自主性与协作的基石——没有它，对学习的掌控与对他人的正向影响就无法发展
**学习目标数量：** 3——知识类型分析揭示了三个真正独立的分支，**必须**拆分以避免评估路径错配

### 能力审视

该能力框架良好，但内部打包了全部三种知识类型的要素。“监控与调整”看似单一能力，实则捆绑了：（a）理解什么是应激反应以及调节如何运作（类型 1——可教授、可测试的知识）；（b）在结构化情境中分析自身模式并选择恰当策略（类型 2——关于自我调节的推理）；以及（c）在长期真实情境中真正做到调节（类型 3——践行中的倾向）。如果将它们折叠进单一的量规评估 LT 中，就只会捕捉到类型 1 和类型 2 要素。类型 3 的践行——恰恰是整件事的核心——会从证据中消失。需要 3 个 LT。这是正确的设计，而非膨胀。

### 第0步：知识类型分类

| LT 分支 | 知识类型 | 评估路径 | 推理依据 |
|---|---|---|---|
| 理解应激反应 | 类型 1 | 带清晰标准的量规 | 存在前置链条：学生必须先理解压力下生理与心理发生什么，才能对策略进行推理。低层次的错误会向上传递——误解应激反应的学生会误用调节策略。 |
| 调节策略分析 | 类型 2 | 推理质量量规 | 任何情境都存在多种有效策略；推理质量决定学生是否选择了恰当策略；分析深度随经验增长；向新情境的迁移是检验标准。 |
| 作为实践的自我调节 | 类型 3 | 多信息源观察 | 该能力仅存在于跨时间与跨情境的践行中。能在情景题中分析策略（类型 2）但在真实情境中无法调节的学生，尚未发展出该倾向。需要观察真实行为。具有知识依存性：需要类型 1 与类型 2 作为前置条件。 |

复合知识类型标记：原始能力定义捆绑了全部三种类型。下文拆解将其分离为拥有不同评估路径的独立 LT。

### 学习目标拆解

**LT1：理解应激反应**
- **定义：** “我能够描述身体与大脑如何应对压力并解释调节策略如何运作”
- **知识类型：** 类型 1
- **评估路径：** 带清晰标准的量规
- **前置条件：** 不适用（N/A）
- **学理依据：** 这是知识基础。如果不理解应激反应期间发生什么，学生就无法推理哪些策略适用或为什么适用。该 LT 可通过解释任务与知识检查高效评估。

**LT2：调节策略分析**
- **定义：** “我能够分析情境并选择契合该情境的调节策略”
- **知识类型：** 类型 2
- **评估路径：** 推理质量量规
- **前置条件：** 不适用（尽管 LT1 知识会深化表现）
- **学理依据：** 这是推理能力。学生能通过多重视角审视情境并推理哪种策略契合。通过需要迁移至新情境的情景任务评估——而非背诵练习过的例子。

**LT3：作为实践的自我调节**
- **定义：** “我能够跨不同场域调节自己对压力的反应。[通过多信息源观察评估——见观察规程。]”
- **知识类型：** 类型 3
- **评估路径：** 多信息源观察——教师笔记、学生自我反思、家长输入、Strive 数据。在发展性对话中综合。非终结性打分。
- **前置条件：** 必须先建立 LT1（理解应激反应）与 LT2（调节策略分析）。唯有当学生具备知识与分析策略库后，类型 3 观察才是有效证据。
- **学理依据：** 这是践行中的倾向。能描述调节（LT1）并分析策略选择（LT2），但在真实情境中不进行调节的学生，尚未发展出自我调节。本 LT 捕捉了其他两个无法捕捉的内容——随时间推移的真实实践。

**拆解检验：**
- **覆盖度：** 三个 LT 共同覆盖了自我调节的完整含义：知道调节是什么（LT1）、推理何时及如何应用（LT2）以及实际做到（LT3）。
- **区分度：** 学生可能懂科学原理但不会应用（LT1 强，LT2/3 弱）。学生可能在情景题中会推理策略但在真实压力下用不出来（LT2 强，LT3 弱）。这三者确实是分离的。
- **可评估性：** LT1 通过解释任务；LT2 通过情景分析；LT3 通过多信息源观察。
- **知识类型检验：** 每个 LT 仅包含一种知识类型。无复合违规。

### 阶段陈述 / 观察指标

**LT1：理解应激反应**
知识类型：类型 1
评估路径：带清晰标准的量规
撰写模式：模式 2

| 阶段 | 陈述 | 进阶杠杆 |
|---|---|---|
| A | 我能够识别我的身体何时感到平静以及何时感到有压力 | 独立性：在成人支持下识别状态；范围：仅限自身身体 |
| B | 我能够描述应激反应期间身体发生什么并说出有帮助的策略 | 推理：描述机制；复杂度：将反应与策略相连接 |
| C | 我能够解释应激反应如何影响思考与行为，并比较不同策略如何针对反应的不同方面 | 推理：解释因果；复杂度：对照机制比较策略 |
| D | 我能够分析个体与情境因素如何影响应激反应并评估哪些调节方法有证据支持 | 迁移：应用于多样情境；推理：关于证据的评价性判断 |
| E | 我能够批判性评估关于应激反应的解释、识别证据何处强有力何处存在争议，并解释个体与情境差异如何影响哪些调节原则适用 | 迁移：将批判性评估应用于证据基础本身；推理：识别一般原则的限度 |
| F | 我能够依托证据基础构建关于自身压力调节画像底层机制的说明，并评估一般调节原则在哪些条件下对我个人而言适用性较低 | 独立性：自主撰写的理论说明；迁移：从证据泛化至个人画像 |

**LT2：调节策略分析**
知识类型：类型 2
评估路径：推理质量量规
撰写模式：模式 1

| 阶段 | 陈述 | 进阶杠杆 |
|---|---|---|
| A | 当感到沮丧时，我能够从提供的选项中选择一个平复策略 | 独立性：受支持的选择；范围：即时情境 |
| B | 我能够针对给定情境考量不止一种策略并解释为什么选择其中一种 | 复杂度：多重选项；推理：论证选择 |
| C | 我能够通过不止一个视角分析情境并选择契合该情境及所涉人员的策略 | 范围：考量情境与他人；推理：多视角分析 |
| D | 我能够为复杂情境评估相互竞争的策略、识别它们之间的张力，并跨不止一个情境论证我的方法 | 迁移：跨情境应用；复杂度：带有张力的竞争性策略 |
| E | 我能够为持续的高风险情境构建调节计划、预判我偏好策略可能失效的条件，并确定应急方案 | 推理：前瞻性与应急规划；范围：持续的高风险情境 |
| F | 我能够为一个全新的高风险情境设计调节方法、结合机制与证据论证我的设计，并参照随时间观察到的结果评估其有效性 | 独立性：自主设计方法；迁移：将原则应用于全新设计问题；推理：对照证据评估自身设计 |

**LT3：作为实践的自我调节**
知识类型：类型 3
评估路径：多信息源观察
前置条件：LT1（理解应激反应）、LT2（调节策略分析）

A阶段指标——教师注意到：
- 当感到沮丧时，学生接受成人的安抚或重定向，并开始回到活动中
- 在非结构化的真实情境中，学生在成人提示下使用一个已命名的平复策略

B阶段指标——教师注意到：
- 在真实困难时刻，学生无需成人提示即可独立启动一项调节策略
- 事后学生能够较为准确地说出自己做了什么来调节

C阶段指标——教师注意到：
- 学生在不同情境中选择不同策略，表现出对“一种情境有效的方法在另一种情境可能无效”的觉察
- 学生在合理时间范围内从挫折中恢复，并重新投入任务或互动

D阶段指标——教师注意到：
- 在持续挑战期间，学生无需外部支架即可维持调节
- 当被问及时，学生能说出并解释自己的调节模式，包括随时间推移发生了什么变化

E阶段指标——教师注意到：
- 学生在情绪完全激活前就能识别失调的早期信号，并在无需成人提示的情况下启动策略，包括在高风险情境中
- 学生在情境进行中基于对“什么有效、什么无效”的实时评估调整策略
- 事后学生能具体反思是什么改变了他们的状态以及下次会做出何种不同选择

F阶段指标——教师注意到：
- 学生在持续的高风险真实世界情境中无需支架或事后成人干预即可展现稳定的调节
- 学生能够构建跨越多年、关于自身调节画像的说明，识别出什么已经改变以及什么条件仍对自己构成挑战
- 学生在高要求情境到来之前主动承担责任，安排好支持自身调节的环境、社交或时间条件

学生自我反思提示：
- A阶段：告诉我本周有一件很难的事以及你当时做了什么
- B阶段：描述本学期你注意到的关于自己如何应对困难时刻的一个模式
- C阶段：对比你注意到的自己调节情况与老师观察到的情况——你们在哪里一致、在哪里不一致？
- D阶段：分析你的调节在不同场域中如何运作，并解释过去一学期发生了什么变化
- E阶段：评估过去一年你的调节是如何变化的——什么发生了转变、什么条件促成了转变，以及你在哪里仍会失控
- F阶段：构建一段关于你长期跨不同高风险情境如何调节的说明——你的画像长什么样、什么仍未解决，以及你接下来需要努力什么

### 已知局限

1. **LT3 证据依赖于观察基础设施。** 多信息源观察要求教师保存带日期、可检索的笔记。在专用观察应用尚未存在之前，教师真正愿意持续使用的最简系统就是最好的系统。无法跨学期检索与对比的笔记只是印象，而非证据。

2. **LT3 具有知识依存性——时机至关重要。** 在 LT1 与 LT2 前置条件合理建立之前，不应启动 LT3 的类型 3 观察路径。在学生具备知识与策略库之前观察其自我调节，产出的将是无效证据。

3. **来源之间的分歧是信息，而非错误。** 如果教师在 LT3 上的观察笔记与学生的自我反思存在分歧，这是应在发展性对话中浮现的发展信息——而非会前必须解决的故障。

4. **倾向不等同于能力。** 一名学生可能在 LT1 与 LT2 上得分很高（他们懂科学原理且能推理策略），但在 LT3 上证据有限（他们在实践中并不调节）。这不是评估失败——这是一个真实且重要的发现。设立三个 LT 正是为了让这一点变得清晰可见。
