# 本技能库的实际应用

这些技能并非纸上谈兵。第 14 领域中的教学法框架——SEEDS 再生型探究循环（SEEDS Regenerative Inquiry Cycle）、发展阶段体系（Developmental Band System）、学习目标撰写方法论（Learning Target Authoring methodology）、量规逻辑系统（Rubric Logic system）以及自主项目设计协议（Self-Determined Project Design Protocol）——正在布达佩斯的一所国际学校中持续研发并开展课堂实践。整个技能库凝聚了 20 年的课程设计与教学实践经验。本项目选择公开构建，是因为它所解决的问题是教育界共同面临的问题，而共同的问题值得拥有共享的解决方案。

[ARCHITECTURE.md](ARCHITECTURE.md) 中描述的三层架构正在积极建设中。上下文引擎与编排器正处于开发阶段。当前的 MCP 服务器将全部 165 个技能暴露为提示词、将 153 个可由模型调用的技能暴露为工具，并提供四个发现工具；本地安装依然是首选的免费路径，同时为远程客户端工作流提供受访问控制的托管 MCP。更新动态将发布在 [garethmanning.substack.com](https://garethmanning.substack.com)。
