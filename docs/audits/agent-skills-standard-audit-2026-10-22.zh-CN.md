# Agent Skills 标准与互操作性审计

日期：2026-10-22。仓库：[GarethManning/education-agent-skills](https://github.com/GarethManning/education-agent-skills)，分支 `main`，修订版本 `6bbbce418f82e11044009c9f3b7373a354de5bd0`。接手时本地检出与远程 `main` 一致且工作区干净。这是一个独立的教育开源项目；不推断任何商业关联。

## 1. 执行评估

**保留现有架构；修复可移植性契约以及若干具体缺陷。** 本项目本身已具备 Agent Skills 形态：165 个独立命名的 `SKILL.md` 目录、连贯的教师/学生工作流、实用的教育 schema、元数据优先发现机制以及正常运作的 MCP 适配器。它无需从无关提示词格式转换而来，也无需扁平化为新的源码树。

**官方参考校验：0/165 通过。项目校验：165/165 通过。隔离的必需 name/description/目录检查：165/165 通过。** 所有文件在项目解析器下均为有效 YAML。官方演示校验器拒绝了 160 个文件中的流式序列；其余 5 个则抵达其字段允许列表检查并失败。在一次性测试目录中将前置元数据重新序列化为块状 YAML 后，全部 165 个文件均抵达——并失败于——该允许列表。这是参考校验器与扩展字段之间的不匹配，而非 165 个技能在所有客户端中均无法运行的证据。规范正文并未明确规定未知键的运行时行为，其 YAML 描述也未禁止 YAML 流式语法。在宣称合规性时请如实报告这些区分。

最高价值的发现包括：Codex 市场源路径越出了根目录而被当前解析器拒绝；12 个刻意设为仅显式调用的技能缺少 Codex 调用策略；默认前置元数据解析器可能从被修改的技能中执行 JavaScript；MCP 锁文件未通过当前的高危依赖门禁；以及针对性的教育证据/安全不一致问题值得修复。全新的 MCP 源码构建通过了全部 42 项测试。注册表与 MCP 打包产物均与规范技能完全匹配。

建议通过一个小型、确定性的便携版分发配置文件实现正式对齐，同时保留当前的源路径与厂商适配器。切勿仅仅为了获得绿色的校验结果而抹除教育元数据。预估核心修复加便携版分发需 **3–5 工程师日**（含验证）；针对性教育审阅增加 **1–2 日**，可选优化增加 **1–2 日**。这些是工作量估算，并非部署请求。

## 2. 仓库架构概览

仓库共有 241 个受追踪文件，包括 20 个领域下的 165 个技能。每个技能目录仅包含 `SKILL.md`；没有随附的技能脚本、参考资料或资产。磁盘上除依赖/Git 目录外找到的所有实际技能文件均与受追踪文件及注册表条目匹配；未发现未注册技能。被忽略的 macOS 元数据与本地构建输出不属于源分发缺陷。

## 6. 安全与供应链发现

**Q0 — 可执行前置元数据（已复现；中等暴露面，必需修复）。** `mcp-server/src/skill-loader.ts:134` 处的默认 `gray-matter` 启用了 JavaScript 前置元数据。一个无害的内存探针执行了其中的标记。技能贡献者或本地文件编辑者可能会引入在加载/打包期间（早于教育校验）运行的代码。CI 的独立打包作业不依赖于源码校验。这并非远程请求代码执行，且当前未发现恶意技能。要求仅接受普通分隔符与纯 YAML 安全解析器；仅禁用默认语言是不够的，因为文档本身可以选择引擎。

**Q1 — 依赖项（已验证的审计失败；实际风险需分类评估）。** 根目录 npm 审计：零。MCP：10 个受影响的包，1 严重 / 2 高危 / 7 中危。当前 `npm audit --audit-level=high` CI 条件会失败。SDK 1.30.0 受[校验内存耗尽漏洞](https://github.com/advisories/GHSA-46jr-4wx8-v453)影响。虽然 HTTP 认证先运行且应用将字节数限制在 1 MiB，但数组 schema 缺少元素数量上限。未测试在该上限下是否会崩溃。将 SDK 升级至 ≥1.32.0 **并显式启用 `maxToolInputElements`**；仅升级仍会保持其禁用。刷新兼容的传递依赖。[严重级别的 proxy-addr 发现](https://github.com/advisories/GHSA-jqcg-44mw-7w3h)需要此处不存在的 trust-proxy 配置/用法；切勿将其描述为已证实的匿名绕过。其他仅限客户端/任务/序列化器的通告均未表现出活跃的应用路径。切勿盲目采纳 npm 对 `gray-matter` 的降级建议。

**Q2 — 提示词替换会损坏字面量输入（已复现；低风险）。** `src/tool-handler.ts:12` 将用户输入直接用作 JS 替换字符串。`literal-$&` 在模板文本中会变成 `literal-[not provided]`；摘要依然正确。改用回调函数、转义 schema 键，并确保后续的占位符清除不会篡改已插入的内容。源文档/学生作品必须保持为数据，而非更高优先级的指令；提示词定界与恶意文档案例属于恰当的轻量级测试，不代表宣称完全防御注入。

**Q3 — 运维边界（已观察/记录）。** 令牌吊销仅针对单个凭据，而不针对派生的 OAuth 访问/刷新凭据。重放/防滥用计数器为实例本地存储，且已如实记录。明确事件处置流程；仅当公共托管服务需要更强保证时才添加共享状态。保留已配置的规范源站、精确重定向、S256、加密短生命周期凭据、通用服务商错误、仅请求头 Bearer 认证、请求体上限、`no-store` 与模拟测试。

**Q4 — 发布/CI 规范（提示性建议）。** 现有本地被忽略的 `dist` 已过时并在最初导致三项测试失败；干净源码构建通过了全部 42 项，因此这并非 `main`/线上回归。增加 `prepack` 新鲜度检查与打包后 CLI 冒烟检查。CI 不包含部署工作流；请保持该边界。固定 Action 修订版/依赖工具及最小权限；对 `api/` 与 `src/` 一并执行类型检查。未打印任何凭据。完整历史/密钥扫描、GitHub 权限配置与生产环境配置超出已验证范围。

**许可：** 源教育内容与文档采用 CC-BY-SA-4.0；署名声明与原创/实践者标签非常有用。单独复制的技能文件夹会遗漏根目录许可证，因此便携包应随附该许可证。根许可证文本明确指明适用于教育内容/文档/示例；请阐明脚本/MCP 的预期软件许可证，而非静默对其重新授权。引用具名研究不代表拥有第三方全文的再分发权。未发现随附的研究 PDF。
