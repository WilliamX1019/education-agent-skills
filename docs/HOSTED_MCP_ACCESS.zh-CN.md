# 公共 MCP 退役与迁移说明

由本库运营的公共 MCP 服务已随 v3.1.0 退役。不再提供公开注册。这个免费、开源的技能库继续通过 [GitHub 发布页](https://github.com/GarethManning/education-agent-skills/releases/tag/v3.1.0)、源码插件、手动提示词以及本地/自托管 MCP 提供服务。公共端点的退役已单独完成验证；详见[发布记录](releases/v3.1.0-publication-record.md)。本说明不声称已吊销历史凭据或删除第三方服务商数据。

## 选择替代方案

- **Claude 或 Codex 源码插件：** 请使用[主配置指南](../README.md#get-started)。请按照 [Codex 指南](CODEX.md#updating-and-troubleshooting)中的说明更新已安装的插件缓存；仅更新本地仓库检出目录可能会使旧缓存继续生效。
- **选择性本地技能：** 下载[便携版 ZIP](https://github.com/GarethManning/education-agent-skills/releases/download/v3.1.0/education-agent-skills-portable-v3.1.0.zip)，解压后将 `agent-skills/` 中选定的完整文件夹复制到客户端的技能目录中。请保留元数据、参考资料、许可证及策略文件。适用时请参考 [Hermes 指南](HERMES.md)。
- **免安装使用：** 打开源技能文件，复制其提示词并查阅仓库中链接的示例。所选 AI 客户端自身的数据处理政策仍然适用。
- **本地 MCP：** 克隆源码并[通过 stdio 构建/运行](../mcp-server/README.md#run-locally-stdio)。无需配置 Vercel、访问令牌或邮件服务。
- **仅支持远程连接器的 MCP 客户端：** 按照[自托管说明](../mcp-server/README.md#self-hosted-http)自行运营经认证的 HTTP 端点，或切换至支持本地/手动路径的客户端。原公共连接器无法自动转换为本地 stdio 连接器。

替换时请移除原公共连接器，并在正式依赖新方案前验证其发现与资源加载情况。旧服务凭据不会自动迁移到你自行运营的端点。本版本不承诺无缝迁移、托管可用性或已签发历史凭据的删除/吊销。

## 自托管责任说明

HTTP、OAuth 与访问申请源码依然保留。自托管者必须主动授权自己的部署、配置自己的源站、密钥与重定向地址，并在启用邮件功能前修改遗留的注册/联系品牌信息。自托管者可自行决定是否提供访问邮件投递功能，若启用则须自行配置邮件服务商与已验证发件人。仓库配置中已禁用由 Git 触发的 Vercel 构建；本地/GitHub 分发无需任何部署。

以下内容描述了保留源码在自托管场景下的行为，并非公开注册邀约，也不构成对线上公共部署的保证。它亦不保证零托管、零存储或零账单费用。

## 认证与凭据行为

- 保留的 HTTP 实现拒绝匿名请求，且仅通过 `Authorization` 请求头接受 Bearer 凭据。切勿将令牌放入 URL 中。
- Claude 连接采用 OAuth 授权码流程，配合现有 Claude 回调地址、精确重定向审批以及强制的 S256 PKCE。
- 新访问令牌在 30 天后过期。除非被单独吊销，否则现有的签名、哈希和明文凭据仍可兼容接受。
- 新授权码经过加密、认证，并绑定至客户端与重定向地址，有效期为 10 分钟。
- 新刷新凭据经过加密，有效期为 30 天，并在使用时轮换。先前签名格式的刷新凭据仍保持兼容。
- 可通过将单个访问或刷新凭据的 SHA-256 哈希添加到 `MCP_REVOKED_TOKEN_HASHES` 中来吊销该凭据；无需轮换全局密钥或让其他所有用户重新连接。吊销仅作用于该精确凭据：不会吊销整个令牌家族、已签发的访问令牌或由其轮换出的新刷新凭据。系统未实现家族级连带吊销。

服务器未引入持久化的共享状态。同一实例内的授权码/刷新令牌重放会被拒绝，且访问申请表单会使用加盐单向指纹（而非明文邮箱键）来应用有界的全局/IP/邮箱速率限制。无服务器实例之间不共享这些内存映射表，且实例重启会清空它们；因此，在缺乏持久化共享状态的前提下，跨实例单次使用强制约束与全局持久限流仍属于明确声明的残余风险。授权服务器采用固定的已注册客户端流程，不支持基于 URL 的客户端元数据文档。

## 请求限制与隐私

OAuth 与访问申请请求体上限为 16 KiB。MCP 请求体上限为 1 MiB。超出限制的请求将收到 HTTP 413 响应，且托管的认证/访问响应均带有 `Cache-Control: no-store`。

工具参数还设有 10,000 个元素的校验预算，统计整个参数对象中的数组元素与对象键总数。这足以容纳测试过的大型测试集——包含 1,000 条虚构结构化记录、每条含 8 个字段（连同必需参数共 9,004 个元素）；更大的结构将返回工具错误。字节限制与元素限制同时生效，因此即使元素很少，超长字符串也可能触发字节上限。

如果自托管者启用了访问邮件路由，邮箱地址、可选姓名/工具以及生成的凭据会被发送至其配置的邮件服务商以尝试投递。可选的使用场景文本仅在内存中检查长度后即被丢弃。应用程序不会创建用户数据库或访问申请表。所选托管平台与邮件服务商可能会处理标准的基础设施/投递数据；详见[隐私政策](PRIVACY.md)。
