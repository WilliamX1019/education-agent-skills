# Education Agent Skills v3.1.0 — 2026 年 10 月 22 日

本次更新保留了技能库跨 20 个领域的 165 个技能，并使它们更易于安装、审查与复用。它将便携版 Agent Skills 下载包与针对教育指导、隐私边界、安装体验及 MCP 运行时正确性的专项改进结合在一起。教育者专业判断与清晰标注的实践者原创方法依然居于核心地位。

## 获取技能库

- [GitHub 发布页 v3.1.0](https://github.com/GarethManning/education-agent-skills/releases/tag/v3.1.0)
- [便携版 ZIP：education-agent-skills-portable-v3.1.0.zip](https://github.com/GarethManning/education-agent-skills/releases/download/v3.1.0/education-agent-skills-portable-v3.1.0.zip)
- [源码插件与手动提示词](../../README.md#get-started)、[Codex](../CODEX.md)、[Hermes](../HERMES.md) 及[本地/自托管 MCP](../../mcp-server/README.md)

解压 ZIP 后可找到包含 165 个技能文件夹的 `agent-skills/` 目录及一份安装说明。将选定的**完整文件夹**复制到客户端文档指定的技能目录中，保留其中的元数据、许可证、参考资料与策略文件。使用下载的技能文件夹无需 Python 或 Node 构建。替换已安装文件夹前请妥善保留本地编辑；在客户端中确认发现与资源访问正常。

## 变更内容

- **教育指导：** 37 项针对性修订解决了学习者理解检查与辅助支持、文献来源忠实度、切合实际的工作负荷、情境支持、隐私以及安全保护（safeguarding）边界等问题。8 份指南将可选示例移至链接资源中；其中两项与上述针对性修订重叠。这意味着共有 43 个不同的规范技能发生变更，122 个保持不变（包括最初标记为保留的全部 108 个技能）。技能 ID、路径与输入/输出接口保持稳定。
- **安装与可移植性：** 规范的富格式源文件继续保留在 `skills/<domain>/<skill-name>/`。生成的便携版本采用标准前置元数据，同时在 `references/education.json` 中完整保留原始元数据、原始正文及本地资源。修正了 Codex 市场注册/安装指导，且 12 个仅显式调用技能配有对应的 Codex 策略文件。插件清单升级至 2.2.0 以便客户端识别更新；已安装的缓存仍需手动刷新。
- **MCP 正确性与安全性：** 非执行式 YAML 解析、单次字面量输入替换、依赖更新、有界校验以及 OAuth 能力通告修正提升了保留运行时的安全性。打包后的 stdio 检查覆盖了构建产物，且嵌套代码块围栏修复恢复了“学习目标（Learning Target）”指南的完整预期提示词。本地 MCP 依然暴露 165 个提示词和 157 个工具。

便携版本使用固定于[上游提交 69ef37e9424c0a7ea9dd2293b559e43ec8176379](https://github.com/agentskills/agentskills/tree/69ef37e9424c0a7ea9dd2293b559e43ec8176379/skills-ref) 的官方 `skills-ref` 0.1.0，通过了 **165/165** 项校验与 **165/165** 项发现提示词收录。详见[官方规范](https://agentskills.io/specification)、[开发者指南](../AGENT_SKILLS.md)与[带日期的验证回执](../audits/agent-skills-build-verification-2026-10-22.md)。

这是针对便携版本在特定时间点的格式检查结果。它不构成基金会官方认证、厂商背书、存在名为“1.0”或“v2”的官方规范版本之声明，也不证明模型遵循度或学习成效。富格式规范头部采用的是独立项目配置文件。开放标准没有全局统一的仅显式调用控制机制；客户端可能会忽略厂商策略文件。

## 公共 MCP 退役

由本库运营的公共 MCP 服务已随本次发布退役；不再提供公开注册。本库继续通过 GitHub 下载、源码插件、手动提示词以及本地/自托管 MCP 提供服务。现有仅使用远程服务的用户需要改用受支持的本地路径或自行搭建的已认证端点；凭据与客户端设置不会自动迁移。详见[迁移指南](../HOSTED_MCP_ACCESS.md)。

本地 stdio 无需配置 Vercel、令牌或邮件服务。自托管者须主动选择自己的部署方式，并自行配置源站、认证及邮件服务商（若使用）。仓库配置禁用了由 Git 触发的 Vercel 部署。GitHub/本地分发无需任何部署；本说明不证明线上端点暂停状态、凭据吊销、服务商数据删除或零基础设施费用。

## 验证与局限

已验收的本地构建回执记录了 **111 项通过的测试：75 项 MCP 测试、21 项技能库测试和 15 项导出测试**，另有 **1 项仅限托管环境的冒烟测试被跳过**。回执还记录了零项项目校验错误、1 项保留的长度提示警告、确定性的便携版导出以及依赖审计零漏洞。这些属于带日期的构建结果，而非新近执行的发布或生产环境检查。

客户端证据涵盖隔离环境 Codex 安装/列表与文件一致性检查、带提示性警告的 Claude 清单校验，以及隔离环境 Hermes 便携版列表与选定资源读取。它不确立真实用户会话激活、自动模型选择、Hub 更新、真实托管 OAuth 连接、远程 CI 或课堂成效。全部 165 个技能均经过筛查，但一手文献审阅深度各有不同。[质量指南](../SKILL_QUALITY.md)阐述了这些边界。

各版本标签保持独立：GitHub 发布版本 `v3.1.0`；源码插件 `2.2.0`；注册表 schema `2.0`；根目录 npm 包 `1.0.0`；MCP npm 包 `0.1.0`；便携版配置文件 `education-agent-skills-portable-1`。本次发布不伴随 npm 发布或许可证变更。

随后已对实际发布与退役操作完成验证；详见[发布记录](v3.1.0-publication-record.md)与[机器可读证据](v3.1.0-publication-evidence.json)。
