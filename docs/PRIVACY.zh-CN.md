# 隐私政策 — Education Agent Skills MCP 服务器

**最后更新：2026 年 10 月 22 日**

## 概述

由本库运营的公共 MCP 服务随 v3.1.0 退役，不再提供公开注册。本地插件、复制的技能以及本地 stdio 均不需要向该服务发起请求。你所选用的 AI 客户端依然适用其自身的模型与数据处理政策；仅在本地安装技能并不会使模型调用变为离线运行。

本声明描述了保留的 MCP 应用源码以及原托管服务的应用层行为。自托管者完全控制其部署环境，且必须提供与其自身配置相符的隐私声明。若自托管者启用了经认证的 HTTP 与访问邮件投递功能，应用程序的行为如下所述。服务退役本身并不证明历史凭据已被吊销或服务商数据已被删除。

## 应用程序处理的数据

对于常规的已认证 MCP 调用，应用程序会校验 Bearer 凭据并处理返回技能内容所需的 MCP 请求。它不会创建用户画像、将教学请求写入应用数据库、使用 Cookie，也不会添加分析/追踪代码。

如果自托管者启用了保留的访问申请页面，该页面接收以下字段：

- 电子邮箱地址（必填）；
- 姓名（选填）；
- MCP 客户端/工具（选填）；以及
- 简短使用场景（选填）。

电子邮箱地址、选填姓名/工具以及生成的访问凭据会被发送至所配置的邮件服务商进行投递。选填的使用场景文本仅在内存中检查长度后即被丢弃，不会包含在邮件中，也不会写入任何存储。应用程序不会将这些字段写入电子表格或应用数据库。应用响应与日志中不包含申请者邮箱、服务商响应详情、访问令牌或令牌前缀。请勿提交学生数据或机密学校信息。

## 防滥用控制与凭据

访问申请端点会为全局、IP 和邮箱速率限制桶派生带密钥的单向指纹。这些有界计数器仅存在于当前提供服务的无服务器实例内存中并会自动过期；明文邮箱地址不会被用作限流映射表的键。由于各实例不共享内存，这属于尽最大努力（best-effort）而非全局持久化的限流机制。

Bearer 凭据仅在 `Authorization` 请求头中接受。新的访问与刷新凭据均设有过期时间，且可通过配置的 SHA-256 哈希吊销单个凭据。OAuth/访问响应均标记为 `Cache-Control: no-store`。

## 第三方服务

原公共服务使用 Vercel；自托管者可自行选择基础设施。在使用 Vercel 的情况下，它可能会根据 [Vercel 隐私政策](https://vercel.com/legal/privacy-policy)处理标准基础设施数据，如 IP 地址、请求时间戳、请求头与运维日志。

当启用保留的访问邮件路由时，邮件通过配置的 Resend 账户发送。Resend 会根据 [Resend 隐私政策](https://resend.com/legal/privacy-policy)处理提供的邮箱地址与消息投递数据。本应用程序不声称对这些基础设施服务商所执行的数据保留拥有控制权。
