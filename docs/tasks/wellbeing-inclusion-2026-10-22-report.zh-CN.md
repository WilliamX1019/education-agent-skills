**保留其余部分：** 既有的不强制集齐五要素规定、不强迫积极情绪、学术严谨性、内容整合、具体教师行动、连贯映射与特权情境警示。

**常规虚构走查：** 虚构选举权历史课保留史料分析、循证辩论与书面论证；学业作品独立于可选情绪反思评估目标。

**边界虚构走查：** 虚构学习者无法走动或不愿披露个人政治观点：采用坐姿/书面历史证据回应、审视正反双方或跳过公开披露，同时保留学术任务；不搞个人歧视模拟体验。

**剩余不确定性 / 审阅问题：** 不从 EPOCH 或特权学校研究中作出新的成效声明。教师使用前核查历史材料与可及性；辩论现已计入过渡时间。

### restorative-practice-protocol-designer

**修改前 → 修改后理由：** 同意/权力不对等警示原本已存在；现将其提前应用于会议选择之前，并贯穿持续口音嘲弄案例。仅凭严重程度不能证明适合召开会议/圆桌，且拒绝参加不移除保护或校规问责。

**受影响界面：** 目的/证据、活跃 Prompt 适用性/路径/准备/输出/自检项、修订后的完整口音嘲弄示例与成本局限。

**保留其余部分：** 会前准备、有序恢复性问题、受影响方发声权、具体且由参与者自主认同的修复、后续跟进、回退与校规后果共存。

**常规虚构走查：** 虚构低层级且适合、参与者愿意并已准备好的冲突仍获得成比例的谈话/会议、有序视角/影响/修复问题以及具体协议/复查。

**边界虚构走查：** 虚构重复口音嘲弄首先触发保护、权力/报复审阅以及分别的支持性谈话。B 可拒绝会面；A 仍须承担责任。跟进核查复发/报复，而非自动重新召集或签字即结案。

**剩余不确定性 / 审阅问题：** 重大使用前需经本地政策与授权引导员审阅。未引入强迫道歉/原谅、保证收益或临床呼吸/重启规则。

### ruler-emotional-literacy-sequence

**修改前 → 修改后理由：** 既有的私密选项出现得晚于公开披露指令；隐私/虚构/跳过选择现已一致。短序列标为改编版，外表不决定情绪，且移除了普适屏息/治疗保证。

**受影响界面：** 目的/证据、活跃 Prompt 改编/隐私/支持边界与自检项、示范/考试序列/学术整合/日常常规、项目局限。

**保留其余部分：** 四大锚点区分、RULER 五项技能（识别/理解/命名/表达/调节）、教师先行示范、精确词汇、调节而非压抑、持续日常常规与临床边界。

**常规虚构走查：** 虚构考试准备仍示范情绪仪表盘（Mood Meter）词汇与元时刻（Meta-Moment）策略选择，随后进行学术整合与持续可选私密签到。

**边界虚构走查：** 虚构学习者拒绝情绪分享或呼吸练习：使用虚构词汇示例、非呼吸策略或跳过，不从沉默推断情绪。持续/严重痛苦转介恰当人工支持，紧急安全走既有学校流程。

**剩余不确定性 / 审阅问题：** 教师核查培训/准备情况及使用所选材料的授权，不捏造许可条款。精确生成脚本与简短改编不代表经过评估的完整 RULER 项目。

### self-efficacy-builder-sequence

**修改前 → 修改后理由：** 拒绝与口头流利度此前被当作因果心理证据，且承诺了首次任务成功；能力/可及性检查现先于效能假设，成功靠实际观察且提供恢复路径。计时器为学习者同意的示例；保留辅助工具与口头规划。

**受影响界面：** 活跃 Prompt 默认值/预检/原则/诊断/自检项、写作诊断与五个任务/脚本、长期支持与局限。

**保留其余部分：** 掌握体验胜过口号、班杜拉四源、具体可信鼓励、微小任务步子、隐私/尊严、归因于循证策略、正当的持续口头规划与成长型思维警示。

**常规虚构走查：** 虚构写作学习者在确认可及的一句话起点后，可使用口述 → 可见文本 → 句子 → 段落，配以具体反馈与可调进阶。

**边界虚构走查：** 虚构学习者口头表达流利但无法写出一句话或反感计时器：不将其归为动机问题；检查书写/可及性需求与教学，保留辅助支持，移除计时压力，且仅在同意与妥善数据处理下使用授权录音。

**剩余不确定性 / 审阅问题：** 该序列不确立诊断、最优时长或经评估的 4–6 任务干预。持续障碍需要恰当的人工评估/支持；反馈必须匹配实际作品。

### trauma-informed-practice-designer

**修改前 → 修改后理由：** 可观察的爆发/流泪与临床口吻主张暗示了创伤因果；现改为支持带替代解释的暂定假设。既有个别/应急/安全保护预案与授权人类审阅先于常规应对草案；移除通用的走廊/退出/等待/无要求规则。

**受影响界面：** 目的/证据、活跃 Prompt 安全/假设/边界/输出/自检项、完整的爆发重构/调适/应对/转介示例与局限。

**保留其余部分：** 不诱导创伤史/不作诊断、教师不充当治疗师、可预测常规、冷静尊严、富有同情心的边界、反馈/可及性、全班安全、重新联结与恰当转介。

**常规虚构走查：** 虚构针对变化/反馈的非紧急困难获得可预测预告、私密具体反馈、尊重空间以及商定的恰当调节选项，同时保留学习目标。

**边界虚构走查：** 虚构扔器材、不安全离开或虐待/自残/自杀担忧立即遵循既有本地/个人/应急/安全保护预案与授权帮助；不等待频次升级或常规转介、不从流泪诊断，也不捏造普适危机协议。

**剩余不确定性 / 审阅问题：** 重大应对草案明确标为需要授权本地政策与相关专家审阅的草案。本工作包不设计或认证缺失的本地临床协议；安全的常规支持实践继续。

### wellbeing-learning-connection-mapper

**修改前 → 修改后理由：** 图谱此前假定有益、将一般 SEL 效应迁移至恢复性实践并捏造本地趋势/时间线；每个箭头现需状态/类型/情境/缺失环节评估，包括未知/矛盾或无支撑路径。领导层理由将已报告/拟议/未知分开并需人工审阅。

**受影响界面：** 目的/证据、活跃 Prompt 中立证据图谱/成效/时机/理由/自检项、替换后的恢复性实践案例与局限。

**保留其余部分：** 诚实性、显式机制、近端/远端区分、条件/成本、交付理由中保留警示、基线需求与平实的领导层沟通。

**常规虚构走查：** 虚构学校考虑投资恢复性实践，获得条件性机制图谱、资源/保护问题、聚合基线提案以及仅使用提供场景事实的可审阅领导层草案。

**边界虚构走查：** 虚构提案缺乏适用干预证据或本地趋势：将学业效果/时机标为未知，保留零效果/不利发现，不导入 SEL 效应或捏造三年事件数据，并允许调整/不采用。

**剩余不确定性 / 审阅问题：** 示例中缺乏恢复性实践特定证据与本地实施细节。图谱如实说明而非捏造预测或为政策变更背书；领导者使用前核实来源、本地事实与资源。
